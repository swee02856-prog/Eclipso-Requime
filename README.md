What is this?
This is a 2d masquerade boss killing shooter, 
basically a demo version of Cuphead if you put it into perspective.
<img width="884" height="583" alt="Screenshot_2026-11-01_11-53-31" src="https://github.com/user-attachments/assets/41a67af8-6e11-407e-a2e5-dfc73cc74e40" />

The Main idea is that the player fights a boss with 1,500 Health and avoid the incoming orb particle attacks
from the boss.
You play as Giovanna, a bald masquerade shooter who is forced to fight a 1,500 health boss until he
defeats the boss or he dies!
The story is very vague because this is just a demo.
**REQUIREMENTS TO PLAY!!**
You can only play this game on a linux based operating system, basically for example
- linux mint
- arch linux
- etc..
**HOW TO DOWNLOAD!**
If you meet the requirements to play you can simply go to releases and download the newest version
of the game and then open it to play.
OR you can download the Source code in this github repo and use an ide to play! (You must have pygame downloaded)
**DIRECTIONS ON GAMEPLAY**
WAD TO MOVE!
W - Jump
A - Left
D - Right

Click - Shoot
**And thats all!** have fun!
